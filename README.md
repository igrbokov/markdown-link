# Markdown Link Checker

Консольный скрипт на `Node.js + TypeScript` для проверки ссылок в Markdown-файлах.

Сообщение для тестового PR

## Что делает

1. Рекурсивно сканирует указанную папку.
2. Находит все `.md` файлы.
3. Извлекает ссылки форматов `[текст](url)` и `file:///...`.
4. Проверяет локальные ссылки (включая относительные от текущего `.md` файла) и выводит их в абсолютном виде.
5. Проверяет внешние `http/https` ссылки через `GET` с таймаутом.
6. Показывает цветной табличный отчёт со сломанными ссылками и статусами.

## Установка

```bash
npm install
```

## Сборка

```bash
npm run build
```

## Запуск

```bash
node dist/cli.js <путь-к-папке> [--timeout=5000]
```

Пример:

```bash
node dist/cli.js ./docs --timeout=3000
```

## Интерпретация отчёта

- `ENOENT` — локальный файл не найден.
- `404`, `500`, ... — HTTP-ответ получен, но ссылка недоступна.
- `TIMEOUT` — превышен таймаут запроса.
- `NETWORK_ERROR` — ошибка сети/резолвинга/соединения.

Если сломанные ссылки найдены, скрипт завершится с `exit code 1`.
